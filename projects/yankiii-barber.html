01 / Full-Stack Web Application

Yankiii Barber Co.

A full-stack barbershop appointment platform for browsing services, choosing a barber, checking availability, and managing bookings.

Problem

Booking a barbershop appointment can involve several decisions: choosing a service, selecting a barber, finding an available schedule, and confirming the appointment. Yankiii Barber Co. brings these steps into one web application while also giving staff an admin interface for managing the booking system.

My role

I designed and developed the project as a full-stack web application, working across the customer-facing interface, booking flow, authentication, backend API, database integration, and admin functionality.

Stack

HTML, CSS, JavaScript, Node.js, Express.js, MySQL, JWT, bcryptjs, Nodemailer, and Express Rate Limit. The application is deployed on Vercel.

A hard problem

One of the more challenging parts was coordinating the booking flow across services, barbers, schedules, and customer authentication. The backend separates these responsibilities into controllers, routes, middleware, and booking utilities so that availability and appointment handling can be managed consistently.

What I would do differently

I would continue improving the system around production readiness, particularly deeper automated testing, more detailed booking management, and additional operational tools for barbershop staff.
